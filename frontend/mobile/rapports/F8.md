- **F8.2 — Écran Compteurs et foyers** (`households_screen.dart`, route `/compte/compteurs`) :
  - les **invitations reçues en haut**, avec Accepter / Refuser ;
  - **une carte par foyer**, qui échoue seule si elle ne se charge pas. Chaque carte montre :
    - les compteurs (référence, puissance souscrite) ;
    - le lieu et mon rôle ;
    - les membres (pastilles, « Vous seul », « Grâce Ngoma · payeur délégué », invitations en
      attente) ;
    - le badge « À payer » ;
  - les états : chargement, aucun foyer, hors connexion, erreur.
  - **D8.3, accès à l'écran** :
    - depuis l'onglet Compte, par un bouton en attendant l'écran Compte de F9 ;
    - depuis « Ajouter un compteur » de l'accueil ;
    - depuis Consommation quand il n'y a aucun compteur ;
    - depuis la notification « invitation reçue ».
- **F8.3 — Ajouter un compteur** (`add_meter_sheet.dart`) :
  - le N° de branchement et le N° client, **vérifiés chez E²C par l'API au moment de l'ajout** ;
  - un foyer existant (ceux dont je suis propriétaire) ou un nouveau foyer (nom et ville). Le
    nouveau foyer est **créé une seule fois**, même si l'ajout du compteur échoue puis réussit ;
  - les erreurs s'affichent sous le bon champ : compteur introuvable chez E²C, déjà rattaché, champ
    refusé ;
  - le succès affiche ce qu'E²C a renvoyé (centre, puissance) et l'historique importé, marqué
    « (données de démo) » ;
  - le bouton « Ajouter un compteur » est fixé en bas de l'écran. Venu de l'accueil ou de
    Consommation, la feuille s'ouvre toute seule.
- **F8.4 — Gérer** (`manage_sheets.dart`, D8.1 et D8.2). Le bouton de la carte affiche « Inviter un
  proche » si le propriétaire est seul, sinon « Gérer ».
  - **Propriétaire** :
    - renommer le foyer (nom obligatoire) ;
    - renommer un compteur (nom facultatif : vide retire le nom) ;
    - membres : « Retirer », ou « Annuler » pour une invitation, **toujours avec une confirmation** ;
    - « Inviter un proche ».
  - **Membre** : une phrase explique que seul le propriétaire peut modifier le foyer, puis
    « Quitter ce foyer » **avec une confirmation**.
  - **Inviter** :
    - le numéro (champ +242), puis le rôle : « Payeur délégué » ou « Lecteur » ;
    - D8.2 : si le numéro n'a pas de compte, on affiche « Ce numéro n'a pas encore de compte
      ElecPay. Demandez-lui de s'inscrire, puis invitez-le. », sans aucun SMS ;
    - une fois envoyée, l'invitation apparaît en attente sur la carte.
  - Les boutons suivent `can_manage`, donc le serveur : l'écran ne recalcule jamais les droits.

## Écarts volontaires avec la maquette

- **Pas d'étape « Vérifier la référence »** : l'API n'a pas de route de vérification séparée. La
  vérification chez E²C se fait au moment de l'ajout. La feuille a donc un seul bouton, « Ajouter ce
  compteur », qui affiche « Vérification chez E²C… » pendant l'envoi. La maquette ne demandait que la
  référence ; l'API exige **aussi le N° client** (guide `FOYERS_COMPTEURS.md`).
- **Nouveau foyer : « Ville » en plus de « Nom du foyer »**, car l'API exige la ville.
- **« payeur délégué » au masculin générique** : la maquette écrit « payeuse déléguée » pour Grâce
  Ngoma, mais le genre d'une personne ne se devine pas à son prénom.
- **Badge « Mode démo »** dans la page, au-dessus des cartes : la règle du projet veut un badge sur les
  données simulées. Dans la barre du haut, il écrasait le titre à 200 %.
- **Invitations reçues** en haut de l'écran : elles ne sont pas dans la maquette, mais sont demandées
  par `DECOUPAGES.md` (F8.2).

## Choix faits en route (et pourquoi)

- **Les invitations ne sont jamais lues dans le cache** : c'était déjà rangé ainsi dans
  `cache_policy.dart` depuis F1.
- **Renommer envoie seulement le champ changé** (`{"name": …}`, `{"label": …}`) : dans l'API,
  `null` efface le quartier ou l'adresse d'un foyer. Envoyer le modèle entier les aurait effacés.
- **Jauge et texte agrandi** : à 200 %, le badge « À payer » passe sous le lieu, et le bouton
  « Gérer » passe sous les membres (vus sur les captures avec les vraies polices).
- **Le bouton « Ajouter un compteur » n'attend pas la feuille** : sinon il tournait derrière elle,
  comme s'il chargeait (vu sur une capture).
