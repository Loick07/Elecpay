# StateBlock

Les blocs d'état vide, d'erreur et la bannière hors connexion.

- **Vide** : pastille neutre, titre qui nomme ce qui manque, phrase qui dit comment le remplir, une action `primary`.
- **Erreur** : pastille `error-soft`, message clair, action « Réessayer » en `secondary`.
- **Hors connexion** : bannière `warning-soft` en haut de l'écran ; le contenu en cache reste affiché avec sa date.
- Textes de référence : table « États d'écran » de la charte.
