# TextField

Le champ de saisie : libellé au-dessus, aide ou erreur en dessous.

- Hauteur 52px, fond `surface-1`, bordure `line`, rayon `radius-md`. Focus : bordure `current` + halo `current-soft`. Erreur : bordure `error`, message `error-text` qui dit comment corriger.
- Le libellé reste visible (pas de libellé qui disparaît dans le champ).
- Téléphone : préfixe +242 fixe, clavier numérique, regroupement automatique « 06 123 45 67 ».
- Références (compteur, facture) en police mono.
