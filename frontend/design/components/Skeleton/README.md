# Skeleton

Le squelette remplace le contenu pendant le chargement, à la forme exacte de ce qui va s'afficher.

- Formes `surface-3`, pulsation douce de 1,4 s (arrêtée si les animations sont réduites).
- Préféré au spinner pour les listes et cartes ; le spinner reste réservé aux boutons.
- Flutter : `skeletonizer` sur le vrai widget, pour que la forme corresponde toujours.
